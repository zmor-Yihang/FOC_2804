# PI 抗积分饱和（Anti-windup）原理笔记

本笔记基于本项目 `User/alg/pid.c` 与 `User/foc/loop_control.c` 的实际实现整理，
说明积分饱和的成因、Back-calculation（反算）抗饱和原理、`Kt` 的选取方法，
以及相对直接积分限幅的优势。

---

## 1. 积分饱和（Integral Windup）的成因

PI 控制器：

```
u_cmd = P + I
P = Kp * e
I[k] = I[k-1] + Kp*Ki*e[k]*Ts
```

执行器输出有物理上限：

```
u_out = sat(u_cmd)
```

当以下两个条件**同时成立**时发生积分饱和：

1. 输出已达执行器极限：`u_cmd > u_max`（或 `< u_min`）
2. 误差仍存在且继续把输出推向饱和方向：`e` 未消除

此时实际输出被卡死，但积分器看不到这一点，仍持续累积。
积分项累积成远超执行器能力的“虚假控制量”。

### 典型场景（本项目 FOC）


| 场景      | 说明                                         |
| ------- | ------------------------------------------ |
| 电流目标阶跃  | `target_iq` 突变，初始误差大，`vq_cmd` 超过 `U_DC/√3` |
| 高速反电动势  | 大部分母线电压用于抵消反电动势，剩余调节电压不足                   |
| 堵转 / 过载 | 已输出最大电流仍无法转动，误差长期存在                        |
| 目标不可达   | 目标速度超过 12V 母线下电机能力                         |
| 机械限位    | 位置目标被硬限位阻挡                                 |
| 母线电压下降  | 软件仍用固定 `U_DC=12V`，真实已饱和但软件未察觉              |

## 2. Back-calculation（反算）抗饱和原理



### 2.1 核心思想

> 不是“发现输出太大就减输出”，
> 而是根据**执行器实际能输出的值**，反算积分器此刻应保存多少，
> 再把积分状态逐步拉回该合理值。



### 2.2 饱和误差定义

```
backcalc_error = u_cmd - u_out
```

- `u_cmd`：限幅前控制器请求
- `u_out`：限幅后实际输出

未饱和时 `backcalc_error = 0`，饱和时为被削掉的部分。

### 2.3 关键等式：饱和误差 = 积分状态偏差

控制器结构（含前馈）：

```
u_cmd = P + I + u_ff
```

按实际输出反算合理积分：

```
I_合理 = u_out - P - u_ff
```

两者相减：

```
I - I_合理 = (P + I + u_ff) - u_out = u_cmd - u_out = backcalc_error
```

所以 `backcalc_error` 精确等于**积分器相对合理值多积累的量**，
因此必须作用到积分器，而不是 PI 输出。

### 2.4 积分修正公式（对应 pid.c）

```c
// pid.c: pid_calculate()
float integral_increment = (kp * ki * error - kt * backcalc_error) * dt;
pid->integral += integral_increment;
pid->integral = utils_clampf(pid->integral, -integral_max, integral_max);
```

即：

```
ΔI = ( Kp*Ki*e  -  Kt*backcalc_error ) * Ts
     └─正常积分─┘   └───反算修正────┘
```

- 第一项：按误差正常积分
- 第二项：把无法实现的部分从积分状态中卸掉



### 2.5 退饱和是指数收敛，不是瞬间重置

忽略正常误差项时：

```
dI/dt = -Kt * (I - I_合理)
```

解为：

```
I(t) - I_合理 = ( I(0) - I_合理 ) * e^(-Kt*t)
```

积分状态按一阶指数逐渐靠近合理值，避免直接赋值造成的跳变与边缘抖动。

### 2.6 一拍延迟（离散实现）

本项目执行顺序：先 `pid_calculate()` → 再联合限幅 → 得到本拍 `backcalc_error`。
因此实际使用的是上一拍饱和误差：

```
I[k] = I[k-1] + ( Kp*Ki*e[k] - Kt*e_sat[k-1] ) * Ts
```

一拍延迟是必然的：必须先完成限幅，才能知道本拍被削掉多少。

### 2.7 本项目电流环的特殊结构

电流环 PI 自身 **不限幅**（`PID_LIMIT_DISABLE`，`pid_calculate` 内部把
`backcalc_error` 清零并提前返回），真正的饱和发生在 `loop_control.c` 的
**dq 电压矢量联合限幅**，`backcalc_error` 由外部写回：

```c
// loop_control.c
backcalc_error_d = v_d_unsat - v_d_out;
backcalc_error_q = v_q_unsat - v_q_out;
// ...
handle->pid_id->backcalc_error = backcalc_error_d;
handle->pid_iq->backcalc_error = backcalc_error_q;
```

联合限幅约束是圆形而非方形：

```
sqrt(vd^2 + vq^2) <= V_limit,   V_limit = U_DC / √3 ≈ 6.93V (12V母线)
```

d、q 两轴按同一比例缩放，方向不变，两轴积分器各自按被削电压回退。

## 3. Kt 的选取



### 3.1 用时间常数理解 Kt

`Kt` 是抗饱和跟踪环的带宽，单位 `1/s`：

```
Tt = 1 / Kt        (抗饱和跟踪时间常数)
```

`Tt` 越小，退饱和越快。

### 3.2 为什么代码取 Kt = Ki

PI 积分时间常数 `Ti = 1/Ki`。取 `Tt = Ti` 即得 `Kt = Ki`：

```c
// pid.c: pid_init() / pid_set_gains()
pid->kt = ki;
```

此时（含前馈）积分平衡点为：

```
I_eq = u_out - u_ff
```

P 项被从积分平衡值中消去，积分不会长期把比例项也存进自身状态。

### 3.3 离散稳定性约束

定义每拍修正比例：

```
α_aw = Kt * Ts
```

- `0 < α_aw < 1`：单调收敛（推荐）
- `α_aw = 1`：一拍到位，激进
- `1 < α_aw < 2`：越过平衡值，交替振荡
- `α_aw >= 2`：发散

工程推荐范围：

```
0.05 <= Kt*Ts <= 0.2   ⇔   Tt ≈ (5 ~ 20) * Ts
```



### 3.4 本项目电流环实测值

```
Ki = 1860.5,  Kt = 1860.5,  Ts = 0.1ms
Tt = 1/1860.5 ≈ 0.537ms ≈ 5.4 * Ts
α_aw = Kt*Ts = 0.186   (每拍修正约 18.6%)
```

约 1.5ms（15 拍）内完成约 95% 修正，对 10kHz 电流环合理。

### 3.5 整定步骤

1. 先整定好 `Kp/Ki`，保证未饱和区响应正常
2. 人为制造安全的短时饱和（受控电流阶跃）
3. 从 `Kt = Ki` 开始，记录 `v_cmd / v_out / backcalc_error / integral`
4. 退饱和慢 → 增大 `Kt`（×1.25、×1.5）
5. 限幅边缘振荡/锯齿/反向过冲 → 减小 `Kt`（×0.8、×0.67）
6. 保留约 20% 稳定裕量



### 3.6 各环不宜盲目共用 Kt = Ki


| 控制环 | Ki     | Kt(=Ki) | Tt = 1/Kt     |
| --- | ------ | ------- | ------------- |
| 电流环 | 1860.5 | 1860.5  | ≈ 0.54 ms（合理） |
| 速度环 | 2.5    | 2.5     | 0.4 s（偏慢）     |
| 位置环 | 0.15   | 0.15    | ≈ 6.67 s（很慢）  |


建议给 `Kt` 独立接口，按各环分别整定，尤其位置环。

## 4. Back-calculation 相对直接积分限幅的优势



### 4.1 两者判断依据不同


|                  | 判断依据                        | 定位      |
| ---------------- | --------------------------- | ------- |
| 直接积分限幅           | 积分变量是否越界 `clamp(I, ±I_max)` | 最终安全护栏  |
| Back-calculation | 请求与实际输出之差 `u_cmd - u_out`   | 正常抗饱和策略 |




### 4.2 具体优势

1. **能识别“积分未到上限但总输出已饱和”**
  `P + I + u_ff` 已超限，而 `I` 本身未越界时，积分限幅不介入，反算能介入。
2. **适配 dq 联合限幅**
  `vd=vq=6V` 各自不超限，但合成 8.49V 已饱和；反算能得到每轴被削的
   `e_sat`，固定上限做不到。
3. **适应动态输出能力**
  母线电压、两轴电压分配、反电动势、弱磁前馈都会改变可用电压；反算用实际
   `u_out`，自动适应；固定 `I_max` 不会变。
4. **按饱和程度连续修正**
  修正量 `∝ e_sat`，轻微饱和小修正、严重饱和大修正，比“到边界就冻结”更平滑。
5. **积分状态跟踪实际输出**
  使 `I → u_out - u_ff`，退饱和更快、超调更小、正反转切换更快。



### 4.3 直接积分限幅的优点（不可完全替代）

- 实现简单、参数少
- 不依赖准确的饱和输出反馈
- 绝对保证积分变量不越界（`Kt` 配错时的兜底）



### 4.4 本项目采用两层策略

```
Back-calculation  →  按实际饱和程度动态修正积分（主策略）
        ↓
积分硬限幅 clamp(I, ±I_max)  →  异常兜底保护
```

电流环尤其需要：`integral_max ≈ 6V`，而某轴真正可用电压随另一轴变化，
例如 q 轴用 6V 时 d 轴仅剩 `sqrt(6.93² - 6²) ≈ 3.46V`；
此时 d 轴积分 5V 未越界却已超实际可用，只有反算能发现。

---



## 5. 对比条件积分（Conditional Integration）

- 条件积分：饱和且误差继续推向饱和时，**直接停止积分**（增量置 0）
- Back-calculation：饱和时**根据** `e_sat` **增大/保持/减小**积分，平滑跟踪实际输出

本项目使用的是 Back-calculation，不是“饱和即冻结”。

---



## 6. 一页速查

```
饱和误差:   e_sat = u_cmd - u_out
积分更新:   ΔI = ( Kp*Ki*e - Kt*e_sat ) * Ts
关键恒等:   e_sat = I - I_合理 = I - (u_out - P - u_ff)
时间常数:   Tt = 1/Kt
稳定约束:   0.05 <= Kt*Ts <= 0.2
代码默认:   Kt = Ki
积分平衡:   I_eq = u_out - u_ff  (当 Kt = Ki)
双层保护:   反算动态修正 + 积分硬限幅兜底
```
